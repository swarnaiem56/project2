# Folder 1 - Initial Lab Work and Video Demonstrations

## Structure
```
Folder 1 - Initial Lab Work and Video Demonstrations/
├── videos/            → place initial class video recordings/links here
├── lab-workbook/       → module-wise lab experiment records (see template below)
└── README.md
```

## Lab Workbook Format
Each experiment inside `lab-workbook/` should be a separate file (e.g. `Module1_Experiment1.md`) following this structure:

```markdown
# Module: [Module Name]
## Experiment: [Experiment Title]

### Problem Statement
[What problem is being solved]

### Objective
[What you aim to learn/achieve]

### Tools, Software & Concepts Used
- Tool/Software 1
- Concept 1

### Source Code / Implementation Steps
[Code block or numbered steps]

### Output (with labelled screenshots)
[Insert screenshot references here]

### Result, Observation & Conclusion
[Brief summary of what happened and what you learned]
```

> Copy this template for each module/experiment and save as a separate `.md` file inside `lab-workbook/`.
